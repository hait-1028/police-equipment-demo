# 警用装备智能管理平台 · 静态作品集

[Open Demo — 查看在线展示](https://hait-1028.github.io/police-equipment-demo/)

用于个人作品集展示的 12 个静态页面，覆盖功能门户、装备工作台、库存统计、实时库存、入库登记、库房管理、装备总览、单警装备、装备借用、保养预警、失效预警和借用登记。

页面样式、图片、字体和导航资源均保存在仓库内，可直接打开 `index.html` 浏览，也可使用任意静态网页服务器预览。页面提供展示用交互，不连接原系统后台。

- `index.html`：展示集首页与页面入口
- `pages/`：12 个静态页面
- `assets/`：本地样式、图片和字体
- `screenshots/`：页面预览图
- `使用说明.md`：离线浏览说明

GitHub Pages 从 `main` 分支根目录发布。
